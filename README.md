# DramaVerse

A premium dark-purple OTT catalog UI built with Next.js. Includes searchable sample drama catalog, category filters, demo details modal, and local in-session My List.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy to Vercel
Push this folder to a GitHub repository, then import it at https://vercel.com/new.

## Notes
This is a front-end demo with fictional sample titles. Authentication, database persistence, and licensed video playback are not connected yet. Use only content you have permission to stream.
